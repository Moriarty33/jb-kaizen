# Claude Launcher

Adds a rocket button to the VS Code editor title bar (top-right of every editor).
Clicking it opens an editor-area terminal at the current window's root and runs `claude`.
For a single-folder window that is the folder itself; for a `.code-workspace` (multi-root) window it is the directory that contains the `.code-workspace` file.

Local-only extension. Not published to any marketplace.
